# 🏡 HomelyHub — Find Your Place, Feel at Home

**A full-stack rental accommodation platform with AI-powered travel planning.**

HomelyHub helps users explore rental properties and plan trips with AI-generated itineraries. It combines a React frontend, a Node.js and Express backend, MongoDB for data storage, and AI-powered features to make accommodation discovery easier.

🌐 **Live Demo:** [Visit HomelyHub](https://homleyhub.netlify.app)

## ✨ Features

- 🏠 **Property Listings** — Browse available rental accommodations.
- 🔐 **User Authentication** — Sign up, log in, and manage your account.
- 🏡 **Accommodation Management** — Add and manage property listings.
- 📅 **Booking Management** — Access booking-related features.
- 🤖 **AI Trip Planner** — Generate personalized travel plans based on destination, budget, trip duration, group size, and interests.
- ✍️ **AI Property Descriptions** — Generate property descriptions using AI.
- 🔎 **Property Search** — Explore properties using search and filtering options.
- 📱 **Responsive Interface** — Browse the platform on different screen sizes.
